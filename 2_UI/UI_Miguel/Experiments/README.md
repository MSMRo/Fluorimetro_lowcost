# Experimentos y demostraciones

## IO Rodeo con AS7341

[`IO_Rodeo_AS7341/`](IO_Rodeo_AS7341/) muestra el funcionamiento del equipo IO Rodeo con su pantalla integrada y el montaje óptico.

## Arduino Mega con cuatro LED

[`Arduino_Mega_4_LED/`](Arduino_Mega_4_LED/) contiene la demostración de la GUI, el Arduino Mega, el AS7341 y cuatro placas LED. El video original se dividió por etapa para que cada resultado pueda revisarse y enlazarse por separado.

Los videos son evidencia funcional, no una calibración de longitud de onda, potencia óptica ni linealidad.

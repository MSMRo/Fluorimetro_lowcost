# Software

## GUI para Arduino Mega y AS7341

[`Arduino_Mega_AS7341_GUI/v1.0/`](Arduino_Mega_AS7341_GUI/v1.0/) es la aplicación actual para el montaje de demostración. Muestra la telemetría multicanal, controla la adquisición y el PWM, refleja la Nokia y registra experimentos.

## GUI anterior para IO Rodeo y TSL2591

[`IO_Rodeo_TSL2591_GUI/v1.0/`](IO_Rodeo_TSL2591_GUI/v1.0/) es la primera interfaz PyQt para observar y controlar la copia TSL del firmware del PyBadge mediante USB CDC.

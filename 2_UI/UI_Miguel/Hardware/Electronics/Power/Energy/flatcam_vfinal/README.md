# Energy, preparación final

Ruta final conservada para la PCB Energy. Incluye proyectos FlatCAM, mapas, pista y taladro. Hay más de una salida NC porque se preservaron ajustes posteriores dentro de la misma fase final.

Antes de mecanizar, identifica cuál archivo coincide con la herramienta, el diámetro de perforación y el método de nivelación disponibles.

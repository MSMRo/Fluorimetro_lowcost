# Excite V5 para láser

Iteración más reciente de Excite y versión seleccionada para los LED específicos por banda. Conserva cobre frontal, borde, perforaciones y el archivo de trabajo Gerber.

Antes de fabricar:

1. Confirma la huella y polaridad del LED que corresponde a cada banda.
2. Revisa tensión, corriente y disipación térmica.
3. Comprueba escala 1:1 de borde y perforaciones.
4. Compara el Gerber con el proyecto KiCad fuente.
5. Realiza una prueba de continuidad antes de conectar el LED y el controlador.

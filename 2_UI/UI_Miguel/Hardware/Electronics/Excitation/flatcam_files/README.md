# Excite V1

Primera preparación de fabricación conservada para Excite. Incluye Gerber de cobre frontal y borde, archivos de perforado, proyectos FlatCAM, mapas de altura y rutas CNC de pista y taladro.

Uso recomendado: conservarla como referencia histórica. Para una fabricación nueva, revisar primero Excite V5.

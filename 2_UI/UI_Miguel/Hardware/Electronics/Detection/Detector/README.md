# Detector V1

Esta carpeta conserva un diseño con STM32L432KCU6, una huella de Raspberry Pi Pico, alimentación analógica y digital, conectores y señales de ADC, DAC, I2C, UART, CAN y depuración.

## Estado

El Detector V1 no se usa en la versión actual del montaje. La detección se realizará con un módulo AST. Los archivos se mantienen para mostrar el avance, permitir comparación futura y evitar perder el trabajo de diseño.

No fabriques ni conectes esta placa como parte del montaje AST sin revisar antes el esquema, la asignación de pines y las tensiones.

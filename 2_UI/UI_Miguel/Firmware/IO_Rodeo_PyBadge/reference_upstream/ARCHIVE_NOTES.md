# Notas de la referencia upstream

Esta carpeta conserva el código de referencia para comparación y atribución. No se presenta como una versión lista para cargar en el montaje actual.

`examples/configuration.json` contiene una coma final en el objeto original y no es JSON estricto. Se conserva para no ocultar una diferencia del material de referencia. Para el montaje adaptado, usa el archivo `configuration.json` del snapshot `v2.0_tsl2591_gui` o `v3.0_as7341` correspondiente.

El enlace a la imagen del README se ajustó a una ruta relativa para que funcione dentro de este repositorio. El código y la licencia se conservan en la carpeta.
